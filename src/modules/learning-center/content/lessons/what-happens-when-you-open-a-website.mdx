# What happens when you open a website?

What happens between pressing Enter and seeing the page?

You type a <Term>web address</Term>, such as www.example.com. Your <Term>browser</Term>, the
app you open websites with, now has work to do. The page lives on a <Term>server</Term>: a
computer somewhere else that answers when asked.

Before the browser can ask, four things happen, in order.

1. **Find the server.** The name is for people. Computers send messages to a number, so the
   browser looks up the site's <Term>IP address</Term>.
2. **Connect.** The browser opens a connection, so both ends know the other is listening.
3. **Lock the connection.** With <Term>HTTPS</Term>, the browser checks the site's ID and
   agrees a secret with it.
4. **Ask for the page.** Only now does the browser send its <Term>request</Term>. The page
   comes back, and the browser draws it.

The page itself arrives only near the end of the run. Everything before it is the work of
getting ready to ask. That is why a site is slowest the first time you visit it: nothing
has been looked up yet.

The page is rarely the last thing, either. The browser reads it and finds that it
needs pictures and styles too. It asks for each of those in the same way.
