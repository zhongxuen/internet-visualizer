# The anatomy of an HTTP message

<Term>HTTP</Term> is a text format, and for one version of it you can read the whole thing
on the wire. A request is a line, some fields, a blank line, and optionally a body.

```http
GET /index.html HTTP/1.1
Host: www.example.com
Accept: text/html
User-Agent: ExampleBrowser/1.0

```

The first line names a method, a target and a version. The lines after it are fields —
key, colon, value — in no significant order. Then a blank line, and that blank line is
not a separator or a stylistic choice: it is the framing. It is the only thing that tells
the receiver the fields have ended and a body may begin.

## The response has the same shape

Status line, fields, blank line, body. `Content-Length` counts the octets of that body,
which is how the receiver knows where the message ends on a connection that is about to
carry another one.

`Host` deserves a mention on its own: it is mandatory in HTTP/1.1 and is the reason a
single address can serve thousands of sites. The connection went to an IP; the field is
what says which of the many sites at that IP you meant.

## Methods are promises

The method is not just a label. Each one carries a contract that caches, proxies and
client libraries rely on without asking the application:

| Method | Safe? | <Term>Idempotent</Term>? | Meaning                            |
| ------ | ----- | ------------------------ | ---------------------------------- |
| GET    | Yes   | Yes                      | Give me this; change nothing       |
| HEAD   | Yes   | Yes                      | The same, but headers only         |
| PUT    | No    | Yes                      | Make this resource be exactly this |
| DELETE | No    | Yes                      | Make this resource not exist       |
| POST   | No    | No                       | Process this, however you like     |

Safe means it changes nothing, so it can be prefetched. Idempotent means sending it twice
leaves the same state, so it can be retried automatically. POST is neither, which is why
a browser warns before resubmitting one.
