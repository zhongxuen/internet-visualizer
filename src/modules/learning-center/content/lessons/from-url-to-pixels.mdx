# From a URL to pixels

Press Enter and nothing visible happens for a while. That while is not one operation, it
is five, and the request for the page is only the fourth of them.

A URL is three parts and the browser uses each in a different stage:

```text
https://www.example.com/index.html
-----   ---------------  ----------
scheme  host             path

scheme -> which protocol, and therefore which port and whether TLS is involved
host   -> the name to resolve into an address
path   -> the only part the server is actually asked about
```

The host has to become a number before anything can be sent anywhere. The scheme decides
whether a <Term>TLS</Term> handshake sits between the connection and the request. Only
then does the path get mentioned at all.

## Five stages, in order, each waiting on the last

| Stage  | What it produces        | Roughly what it costs        |
| ------ | ----------------------- | ---------------------------- |
| DNS    | An address for the name | One round trip, often cached |
| TCP    | An open connection      | One round trip               |
| TLS    | Keys, and an identity   | One round trip on TLS 1.3    |
| HTTP   | The document            | One round trip plus the body |
| Render | Pixels                  | Whatever the page asks for   |

The stages are strictly sequential and each one waits on the whole of the previous. That
is why distance hurts so much: you do not pay the round trip once, you pay it three or
four times before a single byte of HTML arrives — and the page then asks for a
stylesheet, which starts the last two stages over again.

## The render stage is not the end of the network

Getting the HTML does not finish anything. The browser parses it, discovers a stylesheet,
a font, some script and an image, and each of those is another request — some of which
block the first paint until they arrive.

That is the shape of a modern page load: not one transfer, but a dependency tree of
dozens of small ones, each of which waits for its parent to be parsed before it can even
be requested.
